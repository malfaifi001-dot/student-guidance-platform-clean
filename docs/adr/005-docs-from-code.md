# ADR-005: الوثائق من الكود الفعلي وليس الافتراض

- **الحالة**: مقبول
- **التاريخ**: تأسيس `docs/` في هذه الجلسة

## القرار
كل محتوى `docs/` مستخرج من الكود الفعلي (مسارات، دوال، نماذج، تعدّدات، إعدادات). أي معلومة لم تُتحقق من الكود تُكتب صراحةً كـ"غير متوفرة/غير مؤكدة" بدل التخمين.

## السياق
- لا يوجد README معماري أصلي في المستودع يشرح القرارات.
- السجل المكتوب سابقًا للسياق (في أدوات مساعدة خارجية) كان قد احتوى أسماء نماذج (`WorkflowDefinition/WorkflowField/WorkflowFieldOption`) **غير موجودة** في `prisma/schema.prisma` — التأكيد من الملف أثبت أنها غير حقيقية؛ النماذج الفعلية `Workflow/WorkflowStep/DynamicField/DynamicFieldOption`.
- لا يوجد دليل على تاريخ القرارات (commits بدون رسائل توضيحية، مثل `تم` و`تمممممم`).

## العواقب
- **إيجابية**: وثائق موثوقة قابلة للتدقيق؛ التناقضات مصنفة لا مخفية.
- **سلبية**: بعض السياق التاريخي (السبب/القرارات القديمة) قد يكون ناقصًا عمدًا.
