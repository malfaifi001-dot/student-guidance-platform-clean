# خطة فصل لوحات التحكم حسب المسمى الوظيفي

## الهدف

فصل تجربة المستخدم داخل منصة التوجيه الطلابي حسب المسمى الوظيفي المختار عند التسجيل، بحيث يحصل كل مستخدم على لوحة تحكم ومسارات وسايدبار مناسبة له.

المرحلة الحالية تركز فقط على:

- رائد النشاط

أما لوحة المعلم فتؤجل لمرحلة لاحقة بدون تنفيذ الآن.

---

## الأدوار الحالية

الأدوار الموجودة حاليًا:

- ADMIN
- COUNSELOR
- SCHOOL_OWNER
- STAFF

## الدور الجديد المقترح

إضافة دور جديد:

- ACTIVITY_LEADER

ويمثل:

- رائد النشاط
- رائدة النشاط لاحقًا حسب صياغة الواجهة

---

## خريطة التوجيه بعد تسجيل الدخول

| الدور | المسار |
|---|---|
| ADMIN | /dashboard/admin |
| COUNSELOR | /dashboard |
| ACTIVITY_LEADER | /dashboard/activity-leader |
| SCHOOL_OWNER | لاحقًا |
| STAFF | لاحقًا |

---

## خريطة التوجيه بعد التسجيل لأول مرة

عند التسجيل يظهر للمستخدم حقل:

- المسمى الوظيفي

والخيارات الحالية تكون:

1. موجه طلابي / موجهة طلابية
2. رائد النشاط / رائدة النشاط

لاحقًا يمكن إضافة:

3. معلم / معلمة
4. مالك مدرسة
5. موظف إداري

عند اختيار "رائد النشاط"، يتم إنشاء الحساب بدور:

ACTIVITY_LEADER

ثم يتم توجيهه إلى:

/dashboard/activity-leader

---

## لوحة رائد النشاط

المسار:

app/dashboard/activity-leader/page.tsx

الرابط:

/dashboard/activity-leader

## محتوى النسخة الأولى

النسخة الأولى تكون Dashboard تمهيدية هادئة وليست مليئة بالميزات.

الكروت المقترحة:

1. البرامج والفعاليات
2. خطط النشاط
3. المشاركات الطلابية
4. الشواهد والمرفقات
5. تقارير النشاط
6. سجل النشاط

---

## قواعد الفصل بين اللوحات

- لا تظهر خدمات الموجه داخل لوحة رائد النشاط.
- لا تظهر أدوات الأدمن داخل لوحة رائد النشاط.
- لا يظهر Admin Mode إلا للأدمن أو داخل مسارات /dashboard/admin.
- الموجه يبقى في /dashboard.
- الأدمن يبقى في /dashboard/admin.
- رائد النشاط يذهب إلى /dashboard/activity-leader.

## ما لا نفعله الآن

- لا ننشئ لوحة المعلم الآن.
- لا نغير خدمات الموجه.
- لا نغير Workflows البرامج الإرشادية.
- لا نلمس قاعدة البيانات بعمليات reset.
- لا نستخدم prisma db push --force-reset.
- لا نضيف prisma db push داخل build أو start.
- لا نستخدم app/(dashboard).

---

## اختبار المرحلة بعد التنفيذ

بعد تنفيذ الكود لاحقًا يجب اختبار:

1. تسجيل حساب جديد كموجه.
2. التأكد من تحويله إلى /dashboard.
3. تسجيل حساب جديد كرائد نشاط.
4. التأكد من تحويله إلى /dashboard/activity-leader.
5. تسجيل دخول الأدمن.
6. التأكد من تحويله إلى /dashboard/admin.
7. فتح /dashboard يدويًا بحساب رائد النشاط.
8. التأكد من تحويله إلى /dashboard/activity-leader.
9. التأكد من نجاح:

npm run build
